How to Mint Your Own NFT in xolosArmy Community with Tonalli Wallet

Tonalli Wallet lets you explicitly choose xolosArmy Community, obtain that collection's Mint Pass, and create an NFT1 Child cryptographically linked to its Parent on eCash. This guide follows the names and steps in the wallet's current public flow.

Core principle: “Metadata describes. The blockchain proves.”

A name, ticker, JSON document, image, IPFS URI, or a word such as verification may describe an NFT, but it cannot establish collection membership. Tonalli recognizes a Child as community only when valid on-chain NFT1 evidence proves that its Genesis consumed a Group atom from the canonical Community Parent.

Tonalli's trust registry is version 2. It does not let metadata text, a browser environment variable, or a freely entered Parent replace these anchors.

What is a Mint Pass?

A Mint Pass is an SLP NFT1 Group atom, type 129, from the relevant Parent. Creating a Community Child requires exactly one atom from the Community Parent; an Official pass will not work. During minting, that Group atom is consumed as the first input of the Genesis transaction, creating an SLP NFT1 Child, type 65, linked on-chain to that Parent.

  • Community and Official passes are not interchangeable.
  • An NFT Child, mint baton, fungible token, ALP token, or arbitrary Group token cannot replace the correct pass.
  • A Mint Pass price depends on the available offer; this guide does not publish or assume a fixed price.
  • The protocol allows a pass to arrive through a transfer or a valid offer; it does not have to come from one particular counterparty.

What you need

  • An initialized Tonalli Wallet with its recovery backup confirmed.
  • An xolosArmy Community Mint Pass.
  • Enough pure XEC for the 5,500 XEC platform fee, the required dust, and the network fee.
  • An NFT name, description, and image. You may also add an External URL and optional descriptive details.

Step by step

1. Open Tonalli Wallet and go to /nfts

Open a Tonalli Wallet instance you recognize and verify its domain before entering sensitive information. On the /nfts route, open the Mintear NFT tab.

2. Select “xolosArmy Community”

Under Selecciona la colección, choose xolosArmy Community. Do not choose Official / Xolos Ramírez when your goal is a Community NFT. The screen displays the full canonical Parent for your selected collection.

3. Check your Community Mint Pass

Tonalli checks the wallet's UTXOs and enables minting only if it finds a valid Group atom from the Community Parent. The Mint Pass · xolosArmy Community card states that 1 Mint Pass = 1 NFT and that the Parent Token is consumed during minting.

4. If needed, use “Conseguir Mint Pass de xolosArmy Community”

The CTA opens exactly /dex?mode=mintpass&collectionId=community. In the DEX, Colección del Mint Pass must remain set to xolosArmy Community and show the exact Community Parent.

The current purchase flow requires an Offer ID shared by the party that published the offer. Paste it under Comprar Mint Pass (Offer ID), select Cargar oferta, review the quantity and total XEC, and—if they correspond to Community—select Comprar. The DEX freshly checks that the offer belongs to the selected Parent and does not fall back to an Official pass.

5. Return to NFTs

Once the purchase or transfer is confirmed, return to /nfts, open Mintear NFT, and select xolosArmy Community again. Wait for Tonalli to refresh and detect the correct Mint Pass.

6. Complete the actual fields

Enter Nombre (name) and Descripción (description), add an External URL (opcional) if appropriate, and select an Imagen (image). The Datos descriptivos (opcional) section supports stage, sex, color, variety, birth date and place, breeder, father, mother, litter, microchip, and FCM registration.

For Community, these fields are descriptive. Writing “Official,” using a familiar ticker, or entering lineage data does not change the collection or create authenticity.

7. Review “Resumen antes de firmar”

Before submitting, check the following on screen:

  • Collection: xolosArmy Community.
  • NFT1 Group Parent: d6ff881413733a1a6407fa5e1e86537e5fc9f48246bae89b732ca7044993e57a.
  • Mint Pass: exactly one SLP NFT1 Group atom, type 129.
  • Result: an SLP NFT1 Child, type 65, linked to that Parent.
  • Metadata: name, description, and image filename.
  • Fees: the 5,500 XEC platform fee and estimated network fee.

Current limitation: the UI shows this summary before submission, but it does not have a separate canonical two-stage approval modal. The next button starts the uploads and mint, so review everything before selecting it.

8. Select “Subir a IPFS + Mintear”

Tonalli uploads the image first and then the metadata JSON to IPFS. The Child Genesis commits to the metadata URI and hash, but that metadata remains descriptive. After the uploads, the wallet freshly verifies that the exact Community Mint Pass is still available before accessing local signing.

9. What happens on-chain

Tonalli constructs an SLP NFT1 Child Genesis, type 65. Its input[0] consumes exactly the type-129 Group atom from the selected Community Parent. The transaction includes the new Child output, the platform fee, and applicable XEC change; the builder's network fee policy is 1,200 sat/kB.

If the pass is held in one UTXO containing more than one Group atom, the builder may first create an SLP SEND fan-out transaction to obtain an exact one-atom UTXO. That case adds another transaction and its own network fee before the Child Genesis.

10. Save and verify the result

When complete, Tonalli shows NFT minteado, the Child Token ID, and its Txid. Save the TXID and inspect it with a trusted eCash explorer. In Tonalli, select the NFT and use Verificar linaje: the wallet reads Chronik evidence for the Genesis and classifies the Child as community only when its on-chain Parent matches the Community anchor.

Safety before minting

  • Never share your 12 words or paste them into chats, forms, or support tickets.
  • Never share a WIF or private key.
  • Tonalli does not need you to publish your seed; signing takes place locally in the wallet.
  • Verify the Tonalli domain before using the wallet.
  • Check that Community is selected, the Parent is canonical, the pass is correct, and the fees are expected.
  • Save and verify the TXID after minting.

Frequently asked questions

Can metadata turn a Community NFT into Official?

No. Collection membership is proved by on-chain NFT1 ancestry.

Can an Official Mint Pass be used for Community?

No. Each collection requires a Group atom from its own canonical Parent.

Does the Mint Pass remain in my wallet?

Not after it is used: the selected atom is consumed to create the NFT1 Child. Other passes and assets that are not part of the transaction remain in the wallet.
